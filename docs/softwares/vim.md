### Modes

* `i`: insert mode
* `ESC`: normal mode
* `v`: visual mode
* `V`: visual line mode

### Delete stuff

* `x`, `X`: delete character under, before cursor.
* `d`: delete something
* `y`: copy something

### Move around

* `b`, `w`, `e`, previous word (**b**eginning), next **w**ord, **e**nd of next word
* `0`, `$`, beginning and end of line
* `gg`, `G`, beginning and end of file

### Misc

* `u`, Ctrl+R: undo, redo last command
* `:!<command>`, execute a command in shell
* `:r !<command>`, execute a command and insert its output in Vim
